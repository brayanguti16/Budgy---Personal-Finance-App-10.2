# Budgy V10

Personal finance app built with React + Vite + TypeScript.

## Run locally / in Codespaces

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The app currently stores account/session data in the browser localStorage, as implemented in V10.
